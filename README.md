# Projet-pedagogique-EURO-NOK

Test empirique accompagnant la note d'analyse FX du 10 septembre 2026.

Modèle : Δ(EURNOK) = α + β₁·Δ(Brent) + β₂·Δ(DXY) + β₃·Δ(spread 3 ans) + ε
Référence 2023-01-01 → 2026-01-31, test 2026-02-28 → 2026-09-01.

Données exportées le [10/09/2026] : Brent (FRED DCOILBRENTEU), EUR/NOK et DXY
(Yahoo Finance), taux 3 ans NO (Norges Bank), courbe AAA 3 ans (BCE).
